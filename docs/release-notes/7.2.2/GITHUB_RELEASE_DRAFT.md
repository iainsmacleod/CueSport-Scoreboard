## CueSport Scoreboard 7.2.2

Ultimate Pool Balls ball variant, and win animation disabled/hidden for Snooker until a snooker-specific clip exists.

### What's new

- **Ultimate Pool Balls** — new Ball Variant with dedicated ball art on the control panel and overlay
- **Snooker** — win animation skipped and the Win Animation setting hidden for Snooker game / ball variant
