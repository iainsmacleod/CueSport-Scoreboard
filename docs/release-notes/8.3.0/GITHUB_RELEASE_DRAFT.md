## CueSport Scoreboard 8.3.0

**Impromptu tables** — score without OBS. Create a dockless Cloud seat from the Dashboard, run the match from mobile (owner is scoring authority), share scoring-only guest links, and free the seat with End/Call or Destroy Table.

### Highlights

- **Create Impromptu Table** from Tables (tier-limited, separate from Dock Key seats)
- Owner phone/dashboard is authority; guests relay over Cloud WebSocket
- Default **Guest scorer** link (no OBS Dock Owner elevated link on impromptu)
- **Destroy Table** discards a seat without history; End/Call frees the seat after saving
- Table cards: **Ready** / **Admin** / **Guest** presence
- Breaker prompt and Snooker free-ball image parity for impromptu scoring

Local OBS docks continue to work as before. See [RELEASE_NOTES.md](./RELEASE_NOTES.md) for full detail.
