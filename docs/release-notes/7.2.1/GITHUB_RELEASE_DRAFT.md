## CueSport Scoreboard 7.2.1

Patch release — Snooker color-phase and Free Ball fixes, match **Game Information** in stats history, overlay stat cleanup, and snooker tracker reset when editing in-progress frames.

### Fixes

- Snooker clearance colors no longer stuck disabled after the color following the last red
- Free Ball scores lowest ball on table (1 in reds phase; 2+ in clearance)
- Adding frames via Stats match edit resets live snooker tracker state
- Game Information from Setup saved and shown in match history
- P1/P2 overlay stats: Matches Won and Racks/Frames W/L removed (H2H only)
