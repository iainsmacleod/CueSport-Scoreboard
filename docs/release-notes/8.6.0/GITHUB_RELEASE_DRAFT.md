## CueSport Scoreboard 8.6.0

**8.5.0 → 8.6.0** — hosted service moves to **cuesportscoreboard.com**, the OBS dock Cloud button becomes **Manage account** once a hosted Dock Key is saved, and the public homepage gains **Shared Streams** plus an optional promo video.

### Highlights

- **New host** — product links use cuesportscoreboard.com; a stored managed URL on the old host is rewritten. Self-host URLs stay put
- **Manage account** — dock Cloud button opens the dashboard Account tab when a hosted Dock Key is saved
- **Dock Cloud UI** — wider key field, × to clear the key, theme-colored settings popups and links
- **Undo** — 8-ball / Custom chosen ball (and open-table counters) restore with undo
- **Shared Streams** — public tab appears when a promoted stream is live
- **Promo video** — optional homepage tab via `LANDING_PROMO_YOUTUBE_URL`
- **Account** — Privacy Policy and Terms of Service links under Deployment

Local OBS docks continue to work without Cloud. See [RELEASE_NOTES.md](./RELEASE_NOTES.md) for full detail.
