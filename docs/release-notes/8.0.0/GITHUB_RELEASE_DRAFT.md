## CueSport Scoreboard 8.0.0

Cloud dashboard match stats, separate Highest Break / Longest Run, and a fix so Break & Run and Table Run record correctly for 8 / 9 / 10-Ball.

### What's new

- **Cloud Stats** — dashboard leaderboard, recent matches, player rename/edit/delete, Game Info, racks/frames summary
- **Highest Break vs Longest Run** — separate fields for Snooker and Straight Pool
- **B&R / TR fix** — 8 / 9 / 10-Ball run-outs are captured before breaker state resets for the next rack
- **Undo Active Player** — manual player switches undo without reversing pots/points (mobile uses the same dock undo stack)
