Guest links are created and shared from the mobile Share tab or the OBS dock Remote tab. Use this to disconnect every guest scorer across all tables at once.

OBS Dock Keys

One key per OBS CueSport Scoreboard dock; a second dock using the same key will be rejected.

Create a named key for each table, pick a role, then paste it into that OBS CueSport Scoreboard dock’s CueSport Cloud settings.

Share — copy and send the key to another manager of an OBS instance.
Edit — change the seat name/label and role (Administrator, Trusted Operator, or Operator).
Remove — frees the seat and disconnects any dock using it. Create a new key to replace a leaked one.
