OBS Dock Keys

One key per OBS CueSport Scoreboard dock; a second dock using the same key will be rejected.

Create a key for each table you wish to control, then paste it into that OBS CueSport Scoreboard dock’s CueSport Cloud settings.

Share — allows you to copy and send the key to another manager of an OBS instance.
Regenerate — rotates the secret and keeps the same seat name.
Remove — frees the seat and disconnects any dock using it.
Rename — allows you to rename a key to be more user-friendly.
