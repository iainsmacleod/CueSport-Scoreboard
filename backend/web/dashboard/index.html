Connect Your First OBS Scoreboard

Step 1 of 4
1

Add CueSport Scoreboard to OBS

CueSport Scoreboard is the companion OBS product that powers the on-stream scoreboard. It includes two components: the Control Panel Dock, where you manage players, scores, match settings, and Cloud connections; and the Browser Source, which displays the scoreboard in your stream. Install and configure both components in OBS before connecting the Dock to CueSport Scoreboard Cloud for remote control.

View OBS Installation
2

Open Cloud Connection

In the OBS dock, open CueSport Scoreboard Cloud. Use the managed service for the simplest setup, or choose Self-hosting and enter your own Cloud server address.

3

Create a Dock Key

In this dashboard, open Settings → OBS Dock Keys and create one named key for each table or OBS dock.

Running multiple scoreboards on one computer? Give each dock and matching Browser Source a different ?instance= value.

4

Paste, Save, and Connect

Copy the new key, paste it into the OBS dock’s Cloud Connection window, then select Save & Connect. When the status shows connected, your table appears here automatically.

OBS Dock Keys

Create a named key for each table, pick a role, then paste it into that CueSport Scoreboard dock’s Cloud Connection settings.

View — display and copy your key to paste into CueSport Scoreboard dock.
Share — copy and send the key to another manager of an OBS instance.
Edit — change the seat name/label and role (Administrator, Trusted Operator, or Operator).
Remove — frees the seat and disconnects any dock using it. Create a new key to replace a leaked one.
