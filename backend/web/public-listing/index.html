    CueSport Scoreboard Cloud

    Connect every OBS CueSport Scoreboard to one secure hosted service. Run matches from your phone, hand off focused guest controls, manage multiple tables, preserve searchable match statistics, and promote active live streams — all from one Cloud account.

    Open Dashboard Browse Live Streams

    Cloud features require OBS running CueSport Scoreboard (the free OBS dock plugin). Cloud is the hosted relay, remotes, and billing layer — not a standalone scoreboard.

    • OBS CueSport Scoreboard Dock

      Keep authoritative match controls beside OBS while Cloud mirrors live scoring to authenticated mobile and guest devices in real time.

    • One Dock Key per Table

      Connect each OBS dock to its own secure Cloud seat. Manage table access, remote roles, and optional stream promotion centrally.

    • Score From Your Phone

      Move around the venue while controlling players, breakers, balls, fouls, racks, race details, and overall match state.

    • Guest Remote Links

      Hand a scorer a QR link with focused match controls, one active device per link, and no access to account or replay settings.

    • Multi-Table Control

      See every active OBS dock from one responsive dashboard, review the live score, and jump directly into the table that needs attention.

    • Cloud Match Statistics

      Automatically retain completed results, compare leaderboard records, browse recent matches, and filter a player’s history from any device.

    Remote Scoring

    Phone and guest remotes stay synchronized with the authoritative OBS dock. Give floor scorers responsive controls without moving them behind the streaming computer.

    Multi-table Dock Keys

    Assign one secure Dock Key to each OBS CueSport Scoreboard seat. Scale from a single weekly stream to a multi-table tournament under one account.

    Match Statistics & Live Streams
